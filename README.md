# 🎓 Student Information Management – Java

A beginner-friendly Java project that demonstrates how to create, store, access, and process student information using different types of arrays and iteration techniques.

This project covers **Arrays, Enhanced For Loops, Multidimensional Arrays, Jagged Arrays, and Arrays of Objects** with practical student marks examples.

## ✨ Features

### 📊 Array + Iteration
- Store marks of 5 students using an integer array.
- Print all marks using a normal `for` loop.
- Find the highest and lowest marks.
- Calculate the average marks.

### 🔄 Enhanced For Loop
- Print all student marks using a `for-each` loop.

### 📚 Multidimensional Array
- Store marks of 3 students in 3 subjects.
- Display marks in matrix format.
- Calculate the total marks of each student.

### 🧩 Jagged Array
- Create an array with different numbers of subjects for each student.
- Store and print all array elements.

### 👨‍🎓 Array of Objects
- Create a `Student` class with ID, name, and mark.
- Create an array containing 5 Student objects.
- Display each student's details.
- Find the student with the highest mark.

## 📖 Java Concepts Covered

1. **Array** – Creating and accessing integer arrays.
2. **Array Iteration** – Accessing elements using loops.
3. **Normal For Loop** – Iterating with index values.
4. **Enhanced For Loop** – Iterating without index values.
5. **Multidimensional Array** – Working with rows and columns.
6. **Jagged Array** – Working with arrays of different lengths.
7. **Array of Objects** – Storing multiple objects in an array.
8. **Conditional Statements** – Comparing marks using `if` statements.
9. **Finding Highest and Lowest Values** – Comparing array elements.
10. **Total and Average Calculation** – Performing arithmetic operations.

---

## 🚀 Application Structure

All five tasks are implemented in a single `Main.java` file.

- `Main.java` – Contains all five array operations and student information processing.
- `Student` Class – Stores student ID, name, and marks.
